# E.E. Dom Lúcio Antunes - Site Escolar

Bem-vindo ao repositório do site da **Escola Estadual Dom Lúcio Antunes**, localizada em Panorama, São Paulo.

![Status](https://img.shields.io/badge/Status-Ativo-brightgreen)
![Versão](https://img.shields.io/badge/Versão-1.0.0-blue)
![Licença](https://img.shields.io/badge/Licença-MIT-green)

## 📋 Sobre o Projeto

Este é um site completo e moderno para a escola, desenvolvido com **HTML5**, **CSS3** e **JavaScript puro**. O site oferece informações abrangentes sobre cursos, professores, infraestrutura, eventos e permite que alunos e responsáveis entrem em contato com a instituição.

## 📄 Páginas Disponíveis

| Página | Descrição |
|--------|-----------|
| **index.html** | Página inicial com destaques, cursos oferecidos e estatísticas |
| **sobre.html** | Informações sobre missão, visão, valores e histórico da escola |
| **cursos.html** | Detalhes sobre os cursos e modalidades de ensino oferecidas |
| **professores.html** | Apresentação da equipe docente por disciplina |
| **galeria.html** | Galeria de fotos com categorias de eventos e atividades |
| **contato.html** | Formulário de contato, informações e FAQ |

## 📚 Cursos Oferecidos

### 1. **Ensino Fundamental - Anos Finais**
   - **Séries:** 6º ao 9º ano
   - **Horários:** Matutino e Vespertino
   - **Duração:** 4 anos
   - **Características:** Formação integral com foco em competências e habilidades

### 2. **Ensino Médio**
   - **Séries:** 1º ao 3º ano
   - **Horários:** Matutino e Vespertino
   - **Duração:** 3 anos
   - **Destaques:** Preparação para ENEM, aulas práticas, projetos científicos

### 3. **EJA - Educação para Jovens e Adultos**
   - **Níveis:** Fundamental II e Ensino Médio
   - **Horário:** Noturno (19h às 23h)
   - **Público:** Jovens acima de 15 anos e adultos

## 🚀 Como Usar

### Localmente:
```bash
1. Clone o repositório
   git clone https://github.com/gutierredocinho/site-escolar.git

2. Abra o arquivo index.html em seu navegador
   - Use um servidor local para melhor experiência
   
3. Navegue através dos links para explorar as páginas
```

### Com GitHub Pages:
```bash
1. Vá para as configurações do repositório
2. Na seção "Pages", selecione "main" como branch
3. Acesse o site via: https://gutierredocinho.github.io/site-escolar
```
